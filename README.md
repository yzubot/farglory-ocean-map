# 遠雄海洋公園 親子地圖

帶 2 歲小孩（推嬰兒車）的手機優先地圖（花蓮壽豐 遠雄海洋公園／Farglory Ocean Park）：
https://yzubot.github.io/farglory-ocean-map/

- 官網導覽圖疊在真實座標上（Leaflet image overlay），可切換「官網原圖」模式（不變形，藍點用對位公式換算）
- 手機 GPS 即時定位、跟著移動；每個設施顯示推嬰兒車走過去要多久（上坡加時間，入口↔山頂提示搭晴空纜車）
- 設施搜尋（含別名：旋轉木馬、球池、廁所、尿布、推車、纜車、海豚、美人魚、兒童餐、接駁…），有定位時依距離排序
- 依孩子身高／年紀篩「可以玩」的設施（官網「遊樂設施搭乘限制」）、室內設施；八大主題區標籤
- 「今天」：依日期自動判斷（週三奇妙海洋慶典、美人魚泡泡遊行休演；美人魚實境秀週三／平日／六／日票價）、表演時刻（2026/10/26–12/24）、保養日期區間自動套用（愛情摩天輪 11 月保養、12 月只週六日；晴空纜車 12/01–12/23；海盜大驚航停用；戲水冬季推估不開）、飯店接駁車下一班
- 「資訊」：票價與免費條件、付款方式、優惠、推車／置物櫃／育嬰室、推車走法（先搭纜車上山再往下）、雨天備案、餐廳價位、遠雄悅來大飯店、禁止事項
- 「行程」：2 歲平日建議玩法
- 所有欄位都有 tooltip（hover／輕觸，position:fixed），手機版優先，自動深色模式

架構仿 `woc-park-map`（小人國親子地圖）。

## 對位方法與誤差（推估）

官網導覽圖是手繪示意圖、不按比例。真實園區沿海岸山坡：東邊（台 11 線、入口）低，西邊（8 區水晶城堡）高；
導覽圖把「東」畫在下方、「北」畫在右方（約轉 90 度），中段山坡步道被壓縮。

- 控制點 16 個，全部取自 OSM（晴空纜車上下站、燈塔咖啡屋、客服中心、愛情摩天輪、海洋劇場、海洋探索館、水獺館、鯨魚大冒險、嘉年華小吃、鯨魚的夢想家、峽灣、沙木里、多尼漢堡、海洋嘉年華、探險島補貨站）
- 薄板樣條（TPS）加平滑項（λ=0.02），影像無摺疊
- 留一驗證誤差：中位數約 14 公尺，最大約 49 公尺（鯨魚大冒險，園區北緣）；山頂 7 區（大章魚沙灘、海國王號、小藍鯨、水母萬花筒、海底探險家）與 8 區附近控制點少，誤差可能 30–50 公尺
- OSM 有標的設施（洗手間、劇場、餐廳、纜車站等）直接用 OSM 座標；其餘由導覽圖位置換算，畫面上標「位置推估」
- 推車租借、置物櫃、醫務室、入口、飯店接駁站牌的位置是依導覽圖入口區推估
- OSM 部分建築座標為節點平均（建築中心近似）

重新產生：`python3 tools/pois.py && python3 tools/build.py`（需 numpy、Pillow；`tools/src/map_full.png` 是 PDF 第 1 頁 150dpi 裁左 83%）。

## 未驗證／注意

- 假日營業時間只標「以官網為準」（本頁只確認平日 09:30–17:00、最後入園 15:00）
- 戲水池（海豚 3D 戲水池、水漾動感噴泉）冬季不開放為推估
- 嬰兒車能否直接推上晴空纜車未確認
- 育嬰室位置依導覽圖圖例圖示判讀

導覽圖版權屬遠雄海洋公園；本頁非官方，以現場公告為準。純靜態頁，GitHub Pages 提供 https（瀏覽器定位需要 https）。
